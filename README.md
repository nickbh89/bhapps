# bhapps.co.uk

Company landing page for BH Apps (Toll Mate, ParkMate). Plain HTML — no build step.

Deploy: push this folder to a GitHub repo (e.g. nickbh89/bhapps) and import it into Netlify,
or drag the `website` folder onto app.netlify.com/drop. `netlify.toml` sets `website` as the publish directory.
